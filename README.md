# Hangtime for Android

Chat with friends and play games together: Truth or Dare, Impostor, Draw & Guess, Word Clash, Air Puck, Chess and WHOT.

## ⬇️ Download

**[Download Hangtime (all phones)](https://github.com/IdrisNma/hangtime-app/releases/latest/download/hangtime.apk)**

Smaller downloads: [most phones from 2017+](https://github.com/IdrisNma/hangtime-app/releases/latest/download/hangtime-64bit.apk) · [older phones](https://github.com/IdrisNma/hangtime-app/releases/latest/download/hangtime-older-phones.apk)

## Install

1. Open the downloaded file on your phone.
2. If Android asks, allow your browser (or WhatsApp) to **install unknown apps**.
3. Tap **Install**. Needs Android 7.0 or newer.

No phone? Play in your browser: **https://hangtime-dg.web.app**
