# Hangcove for Android

Chat with friends and play games together: Ludo, WHOT, Chess, 8-Ball Pool, Truth or Dare, Impostor, Draw & Guess, Word Clash and Air Puck. Plus Vibes, Channels and live scores.

## ⬇️ Download

**[Download Hangcove](https://github.com/IdrisNma/hangcove-app/releases/latest/download/hangcove.apk)**: works on every Android phone (Android 7.0 or newer: Samsung, Tecno, Infinix, itel, Xiaomi/Redmi, Oppo, Vivo, Pixel and more).

Short on data? [Smaller download](https://github.com/IdrisNma/hangcove-app/releases/latest/download/hangcove-64bit.apk) for phones from about 2017 on. If it won't install, use the main download above.

## Install

1. Open the downloaded file on your phone.
2. If Android asks, allow your browser (or WhatsApp / File Manager) to **install unknown apps**.
3. Tap **Install**. On Xiaomi / Redmi / POCO, if a security check appears, tap **Continue** or **Install anyway**.
4. Open it from the button on the install screen, or find **Hangcove** in your app list: swipe up on the home screen (or open the app drawer) and search "Hangcove".

**Had Hangtime before?** Hangcove is the same app with its new name. It installs as a new app: sign in with the same email and your friends, chats and coins are all there. Then uninstall the old Hangtime.

No phone? Play in your browser: **https://hangcove.web.app**
